# Sistem Persediaan ATK
Sistem Pembelian Persediaan ATK pada Usaha Stationery merupakan sistem berbasis web yang dirancang untuk membantu proses pencatatan dan pengelolaan pembelian barang alat tulis kantor (ATK) dari pemasok. Sistem ini menggunakan HTML, CSS, dan JavaScript pada bagian frontend serta Supabase sebagai basis data untuk menyimpan informasi pemasok, barang, dan transaksi pembelian. Dengan adanya sistem ini, proses pencatatan pembelian diharapkan menjadi lebih terstruktur, akurat, dan efisien sehingga memudahkan pemilik usaha dalam memantau transaksi pembelian dan persediaan barang.
